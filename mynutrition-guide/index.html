MyNutrition guide

How to Use My Nutrition

Learn how to get access, use your stores, and manage your recipes and data.

Open MyNutrition

Access is required to use MyNutrition.

Getting started

  1. Get access

    Give your administrator the email address you will use to sign in. You can log in after they grant that email address access.

  2. Get your store code

    You need a store code to join a shared store, and only your administrator can provide it. In the recipe catalog, choose Join Store; in MyNutrition Admin, choose Join. Enter the code to join.

  3. Start with your personal store

    You will also have your own empty store, named with your name and “MyNutrition” (for example, “Marie MyNutrition”). Its data is separate from other stores, so you can use it as your personal drink library.

Stores, access, and your data

Admin access and shared changes

With admin access, you can edit any store you have access to. Changes are shared with everyone who uses that store. For example, if Clint changes a store’s colors, everyone will see the new colors in the recipe catalog and MyNutrition Admin.

Adding, editing, or deleting recipes affects everyone who uses the store. For example, if Marie deletes a drink, it will no longer be available to anyone using that store.

Back up your store

In MyNutrition Admin, choose Download Recipes to download the data currently loaded in the editor as a JSON file. Keep the file somewhere safe as a backup. I keep copies of shared store data, but I do not have a copy of your personal store, so be sure to download a backup of it.

Make categories your own

Starter stores include drink categories; “Loaded Specialty” is one example. You can organize categories however you like—for example, by drink type or holiday, such as Christmas, Thanksgiving, or the Fourth of July.

You cannot delete a category while recipes are assigned to it. Move those recipes to another category first.

Using MyNutrition Admin

Choose the store you want to work on before making changes. Store settings, recipes, categories, and flavor profiles belong to the selected store.

Choose or share a store

Use the store menu at the top of MyNutrition Admin to switch between stores you can access. To join a store, select Join and enter the code from your administrator.

If you own the selected store, Share Number displays its join number. Share it only with people you trust: anyone with access to MyNutrition and that number can join and edit the store.

Change the store name and colors

Each store has its own name and screen colors. Select the store you want to customize, open its store panel, and use Change Name to rename it. Open Screen colors to adjust that store’s page, card, and button colors. The selected store’s settings appear in both the recipe catalog and admin screen for everyone using that store; other stores keep their own settings.

Manage categories and flavor profiles

Open Categories and choose Add Category to create one. Use Edit or Delete beside a category to change or remove it. A category can only be deleted after all its recipes have been moved to another category.

In Flavor profiles, add, edit, or remove the labels used by the catalog’s flavor filter. These can be flavors or another useful word or phrase, such as a customer’s name. The filter finds that text in drink names and ingredient names.

Add and edit recipes

Choose Add Recipe, enter a drink name, and choose a category. Add each ingredient by name, set its position to Top or Bottom, and enter its cost. Use Add ingredient for more rows. Choose Ok to close the form, then choose Save to save your changes to MyNutrition.

Use the recipe search to find a drink, then choose Edit or Delete. Deleting a recipe affects everyone who uses that store.

Save your changes: Changes are staged while you work. Choose Save to save them to MyNutrition, and wait for the save confirmation. Download Recipes creates a separate JSON backup; downloading alone does not save changes to MyNutrition.

Browse the recipe catalog

  1. Choose a store

    If you have access to more than one store, select one from the store menu. To join another store, choose Join Store in the recipe catalog or Join in MyNutrition Admin, then enter the code from your administrator.

  2. Find a recipe

    Search by drink name or ingredient name. Narrow the results by category, or open Filter by flavor and select one or more profiles.

    Use flavor filters your way

    You do not assign a flavor to each ingredient. Instead, add a flavor profile in MyNutrition Admin and select it to find drinks whose name or ingredient names contain that word or phrase. Profiles do not have to be flavors: for example, you could use a frequent customer’s name to find drinks with that name in the drink or ingredient text.

  3. Explore ingredients

    Each recipe card lists the drink’s name and ingredients, organized into top and bottom sections.

  4. Let MyNutrition pick one

    Choose Pick One to get a drink suggestion from the selected store. Select the suggested drink’s name to find it in the recipe list.

Helpful tips

Search, category, and flavor filters work together. If a recipe you expect is missing, check your search and each selected filter.

You will only see stores you have access to. Ask your administrator to grant access or provide a store code if you want to join another store.
