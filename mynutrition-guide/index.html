How to use MyNutrition

  1. Choose a store

    If you have access to more than one store, select one from the store menu. To join another store, choose Join Store and enter the store ID shared by its owner.

  2. Find a recipe

    Search by recipe name or ingredient. Narrow the list with a category, or open Filter by flavor and select one or more flavors.

  3. Explore ingredients

    Each recipe card shows its name and ingredients, arranged in top and bottom sections.

  4. Let MyNutrition pick one

    Choose Pick One for a drink suggestion from the current store. Select the suggested drink name to find it in the recipe list.

Helpful tips

Search, category, and flavor filters work together, so clear or change a filter if a recipe you expect is not showing.

Your available stores and recipes depend on the access provided to you. Ask the store owner for a store ID if you need to join another store.
